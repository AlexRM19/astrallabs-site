# astrallabs.eu

Сайт студии Astral Labs: страницы приложений и политики конфиденциальности.
Статика на GitHub Pages, без сборки — правишь HTML, пушишь, сайт обновился.

Репозиторий **публичный** намеренно: Pages на бесплатном тарифе иначе не
работает, а держать здесь что-то закрытое нечего. Экономика и планы живут
в репозиториях самих приложений.

## Структура

```
index.html            студия — он же «официальный сайт организации» для Google
lexio/                Lexio + политика
bazi/                 Bazi Compass + политика
support/              поддержка (обязательна для карточки в Play)
style.css             стили внутренних страниц (светлая тема, до переезда на theme.css)
theme.css             тема из Claude Design: тёмно-синяя, Newsreader + IBM Plex; главная уже на ней
favicon.svg           монограмма из логотипа
CNAME                 домен для Pages
.nojekyll             отключает Jekyll: он нам не нужен и только мешает
app-ads.txt.template  НЕ переименовывать, пока нет реального pub-ID — см. файл
```

## Как обновлять

Обычный коммит в `main` — Pages пересобирает сайт сам, обычно за минуту.

Политику конфиденциальности нельзя править задним числом молча: если меняется
то, что приложение делает с данными, сначала обновляется политика и дата
«Last updated» в ней, и только потом выходит версия приложения.

## Что тут намеренно не так, как кажется

**Две политики, а не одна общая.** У приложений противоположные модели данных:
Lexio не собирает ничего и не имеет сервера, Bazi Compass хранит дату и место
рождения, переписку с ИИ и покупки. Общая политика была бы неверна для обоих —
для Lexio она преувеличивала бы сбор, для Bazi преуменьшала.

**Реквизиты фирмы в подвале каждой страницы.** Это не украшение: Google при
верификации организации сверяет, что сайт принадлежит заявленному юрлицу, а
польское право требует идентификационных данных предпринимателя на сайте.
